# 토픽 노트 생성

과목 목록 파일 하나를 받아 토픽당 노트 하나를 만든다. `├──` 트리면 중간 분류 노트도 만든다.

## 입력

- 사용자가 준 과목 목록 `.md`. 파일명은 `04_디지털 서비스.md`처럼 `숫자_`로 시작한다.
- `#` 제목이 출제빈도를 바꾼다. `출제빈도 '상'`, `'중'`, `'하'`, 또는 `출제예상`. 제목 아래의 빈 줄이 아닌 한 줄이 토픽 하나다. 이 형식에는 중간 분류가 없다.
- `├──` 트리는 세 층이다. 맨 위가 출제빈도, 중간이 목차 분류, 맨 아래가 토픽이다. 깊이는 `│` 개수가 아니라 `├──`·`└──`가 있는 칸으로 읽는다.
- 양식은 `.obsidian/templates.json`의 `folder` 아래 `template.md`다.

## 실행

저장소 루트에서 실행한다.

```bash
python3 .grok/skills/topic-notes/scripts/split_topics.py --source "<과목 파일>" --dry-run
python3 .grok/skills/topic-notes/scripts/split_topics.py --source "<과목 파일>"
python3 .grok/skills/topic-notes/scripts/split_topics.py --source "<과목 파일>" --category "<중간 분류>" --dry-run
python3 .grok/skills/topic-notes/scripts/split_topics.py --source "<과목 파일>" --category "<중간 분류>"
```

한 중간 분류만 만들 때는 `--category "분류 이름"`을 붙인다.

사용자가 생성을 요청했으면 dry-run으로 경로와 개수를 확인한 뒤 바로 실행한다. 스크립트 없이 노트를 직접 만들지 않는다.

## 규칙

- 토픽 노트는 파일 번호와 같은 과목 폴더에 둔다. 본문은 템플릿에 있는 것만 복사한다.
- 트리의 중간 분류마다 `과목 폴더/분류/분류 이름.md`를 만든다. 같은 이름은 노트 하나다. 본문은 출제빈도 절과, 그 절의 토픽으로 가는 상대 경로 링크다.
- 토픽 본문에는 분류 링크를 넣지 않는다. 연결은 분류 노트의 링크와 토픽의 백링크로 본다.
- 이름이 비슷해도 목록의 문자열이 다르면 분류를 합치지 않는다.
- 이미 있는 파일은 건너뛴다.
- 과목 목록과 `template.md`는 수정하지 않는다.
- 커밋하지 않는다.

## 보고

스크립트가 출력한 폴더, 태그, 생성 수, 건너뛴 수, 출제빈도별 개수, 바뀐 파일명, 분류 노트의 생성·건너뜀을 알린다.
