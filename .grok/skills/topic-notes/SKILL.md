# 토픽 노트 생성

과목 목록 파일 하나를 받아 토픽당 노트 하나를 만든다.

## 입력

- 사용자가 준 과목 목록 `.md`. 파일명은 `04_디지털 서비스.md`처럼 `숫자_`로 시작한다.
- `#` 제목이 출제빈도를 바꾼다. `출제빈도 '상'`, `'중'`, `'하'`, 또는 `출제예상`.
- 제목 아래의 빈 줄이 아닌 한 줄이 토픽 하나다.
- 양식은 `.obsidian/templates.json`의 `folder` 아래 `template.md`다.

## 실행

저장소 루트에서 실행한다.

```bash
python3 .grok/skills/topic-notes/scripts/split_topics.py --source "<과목 파일>" --dry-run
python3 .grok/skills/topic-notes/scripts/split_topics.py --source "<과목 파일>"
```

사용자가 생성을 요청했으면 dry-run으로 경로와 개수를 확인한 뒤 바로 실행한다. 스크립트 없이 노트를 직접 만들지 않는다.

## 규칙

- 노트는 파일 번호와 같은 과목 폴더에 둔다.
- 이미 있는 파일은 건너뛴다.
- 과목 목록과 `template.md`는 수정하지 않는다.
- 템플릿에 있는 본문만 복사한다. 템플릿에 없는 문장은 넣지 않는다.
- 커밋하지 않는다.

## 보고

스크립트가 출력한 폴더, 태그, 생성 수, 건너뛴 수, 출제빈도별 개수, 바뀐 파일명을 알린다.
