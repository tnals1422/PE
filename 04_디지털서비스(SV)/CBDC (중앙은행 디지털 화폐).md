# 핵심
## 정의

> 디지털 화폐 기술을 활용해 중앙은행이 발행·관리하는 디지털 법정화폐

가상자산 확산과 디지털 경제 전환에 대응하여 
현금과 동일한 법정통화의 디지털 지급수단 제공을 위해 
디지털 화폐 기술을 활용해 
중앙은행이 발행·관리하는 디지털 법정화폐

## 키워드

| 키워드                                | 설명                                                                     |
| ---------------------------------- | ---------------------------------------------------------------------- |
| 디지털 법정화폐<br>(Digital Legal Tender) | - 중앙은행이 직접 전자적 형태로 발행 및 관리하는 법정화폐                                      |
| 단일 원장 방식<br>(Account-Based)        | - 신뢰받는 중앙관리자(중앙은행 등)가 **계좌 및 관련 거래 정보를 직접 보관·관리**하는 **계좌 기반** 구현 방식    |
| 분산 원장 방식<br>(Token-Based)          | - 각 참여자가 원장을 보유하며 합의 절차를 거쳐 **동일한 거래 기록을 복수 원장에 갱신**하는 **토큰 기반** 구현 방식 |
| CBDC 전자지갑<br>(CBDC Wallet)         | - 사용자가 **CBDC를 보관**하고 송금·결제 **트랜잭션을 생성 및 전달하기 위해 사용**하는 핵심 인프라         |
| 거래 검증 및 합의 절차 (Consensus)          | - 분산 원장 환경에서 **거래의 무결성을 검증**하고 **이중 지불을 방지**하는 **상호 검증 메커니즘**          |
