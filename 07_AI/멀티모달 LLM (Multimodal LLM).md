# 핵심

텍스트, 이미지, 음성, 영상 등 다양한 형태의 데이터를 입력받고 생성하는 환경에서(Where), 

이종 데이터 간의 통합적 이해와 복합적인 추론 및 콘텐츠 생성을 위해(What), 
텍스트, 사진, 동영상, 음성 등 **서로 다른 형태의 여러 데이터(Multi-modal)를 한 번에 받아들여 이해하고, 이를 바탕으로 통합적인 답변이나 새로운 콘텐츠를 생성**하는 지능형 AI 기술입니다.


모달리티 간 정렬(Alignment), 융합(Fusion) 및 통합 추론(Multimodal Reasoning) 기술을 제공하는(How) 인공지능 대규모 언어 모델(Entity)


- **Where (어디에서, 어떤 맥락에서 등장했는가)**:

- **What (그것은 무엇을 하는가, 핵심 기능은 무엇인가)**:
    - 
- **How (어떤 방식으로 작동하는가, 어떤 원리인가)**:
    - 각 데이터(텍스트, 이미지, 음성)를 전용 인코더(Vision Transformer, STT 등)로 변환한 후, **공통 임베딩 공간(Shared Embedding Space)**에서 각 모달리티 간의 의미적 관계를 교차 정렬(Cross-Modal Alignment)하여 학습·추론합니다.
- **Entity (그것의 정체는 무엇인가, 어떤 범주에 속하는가)**:
    - 인간의 오감 정보 처리 메커니즘을 모방하여 범용 인공지능(AGI) 및 피지컬 AI(Physical AI)로 진화하는 **차세대 대형 언어 및 생성 모델(LMM/VLM) 아키텍처**입니다.

> **[정보관리기술사 답안지 수준 한 문장 정리]**  
> **"멀티모달(Multimodal) AI는 텍스트, 이미지, 음성, 비디오 등 다중 모달리티 데이터를 공통 임베딩 공간으로 통합 및 교차 정렬(Cross-Modal Alignment)하여 수용·추론·생성하는 차세대 대형 언어 및 생성 모델(LMM/VLM) 아키텍처이다."**

## 🔑 멀티모달 LLM 핵심 키워드 Top 5

핵심1 - 멀티모달 입력·출력(Multimodal I/O) : 텍스트, 이미지, 음성, 영상 등 서로 다른 유형의 데이터를 입력받아 분석하고, 텍스트·음성·이미지 등의 형태로 결과를 생성하는 기능이다.

핵심2 - 모달리티 정렬(Modal Alignment) : 서로 다른 데이터 유형의 의미적 관계를 연결하는 기술이다. 예를 들어, 이미지 속 객체와 텍스트 설명을 대응시켜 시각 정보와 언어 정보를 함께 이해하도록 한다.

핵심3 - 모달리티 융합(Multimodal Fusion) : 텍스트, 이미지, 음성 등 여러 데이터의 특징을 결합하여 단일 모달리티만으로는 파악하기 어려운 복합적인 정보를 이해하는 기술이다.

핵심4 - 멀티모달 추론(Multimodal Reasoning) : 여러 모달리티에서 얻은 정보를 종합하여 상황을 해석하고 문제를 해결하는 능력이다. 예를 들어, 차트 이미지와 자연어 질문을 함께 분석해 데이터의 의미를 추론한다.

핵심5 - 통합 임베딩 및 표현(Unified Representation) : 서로 다른 유형의 데이터를 모델이 처리할 수 있는 공통 또는 연계된 표현 공간으로 변환하여, 모달리티 간 의미 비교와 통합 처리를 가능하게 하는 기술이다.
